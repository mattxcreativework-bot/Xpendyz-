# Xpendyz-
A modern code editor combining manual coding with AI-assisted programming, designed to make software development more intuitive and accessible.

About the Project

Xpendyz is my first independent project, created with a simple idea in mind: making programming and development more accessible.

I believe that learning to code should not be an opportunity reserved for people with expensive computers, advanced equipment, or years of experience.

My goal is to create a more approachable environment where people can explore programming, organize projects, and take their first steps into the world of technology — even when using a smartphone as their primary device.

Technology should open doors, not create barriers.

 My Purpose

Xpendyz is built around three main principles:

Accessibility: Making coding tools easier to approach.
Inclusion: Creating a welcoming environment, especially for beginners.
Opportunity: Encouraging people to develop skills and explore possibilities in the digital world.

I believe that access to knowledge and technology can be an important first step toward new opportunities.

 Main Features

Code editing environment.
Project organization.
AI Assistant.
User account system.
Credits and subscription plans.
Local storage.

 Project Journey

Xpendyz is my first published project.

It may not be perfect, and there are still features to improve, visual details to refine, and ideas to explore.

But I believe a project does not need to be perfect to deserve a place in the world.

It needs to exist so it can be tested, improved, and developed further.

Publishing this first version represents an important milestone in my journey as an independent developer.

 My Vision

My intention is not simply to create another code editor.

I want to contribute to a future where learning, creating, and working with technology feels more accessible to everyone.

Every person should have the opportunity to explore what technology can make possible.
